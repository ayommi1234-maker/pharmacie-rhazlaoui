# Photos des robes

Placez ici vos photos de robes (format `.jpg` ou `.webp` recommandé, portrait).

- Nommez-les simplement, par ex. `caftan-001.jpg`.
- Dans `src/data/modeles.ts`, mettez le champ `photo` à `/products/caftan-001.jpg`.
- Idem pour les tissus (`src/data/tissus.ts`) et décorations (`src/data/decorations.ts`).

`placeholder.svg` est l'image par défaut affichée tant qu'aucune vraie photo n'est fournie.
Ce sont des **données de démonstration** : n'utilisez que des images dont vous avez les droits.
