# Médias de la publicité vidéo

Placez ici 5 à 8 vraies photos (ou courtes vidéos) de robes pour la publicité Remotion.

- Nommez-les `robe-1.jpg`, `robe-2.jpg`, … jusqu'à `robe-8.jpg`.
- La composition (`src/remotion/`) les charge automatiquement si présentes ; sinon
  un fond dégradé de secours s'affiche.
- N'ajoutez aucun média protégé par des droits d'auteur.
- La vidéo exportée (`pub-robe.mp4`) sera également écrite dans ce dossier.
