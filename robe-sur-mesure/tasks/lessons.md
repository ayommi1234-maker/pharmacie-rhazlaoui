# Leçons du projet

## 2026-08-25 — Références avant conception

- Toujours effectuer une recherche web avant de concevoir un guide visuel ou pédagogique.
- Comparer plusieurs références spécialisées, puis utiliser leurs conventions sans copier leurs images.
- Pour les mensurations de couture, valider les points anatomiques auprès de sources de patronage ou de couture reconnues.
- Une belle visualisation ne suffit pas : le tracé doit suivre le geste réel (tour complet, dos, coude plié, point d'épaule, os du poignet).
