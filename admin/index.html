Comment modifier votre site ?

  1. Modifiez les prix et badges dans les formulaires ci-dessous, puis cliquez "Sauvegarder"
  2. Pour ajouter une photo : mettez le chemin de votre image dans le champ imagePerso
  3. Pour activer une offre : activez le toggle "Actif" dans l'onglet Offres
  4. Les modifications sont exportées dans le fichier products-data.js — copiez le code généré
